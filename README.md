# PurpleShield IDS

PurpleShield IDS is a beginner-friendly Intrusion Detection System (IDS) built using Python and Scapy.

It monitors live network traffic, analyzes packets, detects suspicious activities, and logs attacks in real time.

---

## Features

- Live packet sniffing
- TCP packet monitoring
- UDP packet monitoring
- ICMP packet monitoring
- SYN Flood detection
- Port Scan detection
- Real-time packet statistics
- TXT attack logging
- CSV attack logging
- Colorized terminal output

---

## Technologies Used

- Python
- Scapy
- Colorama
- CSV
- Git & GitHub
